# Chiuahua-MK8 - WRO 2025 Autonomous Vehicle Project

Welcome to the Chiuahua-MK8 repository! This project contains all the development work for our autonomous vehicle designed for the World Robot Olympiad (WRO) 2025 competition.

## 📖 Engineering Journal

**👉 Start here: [WRO 2025 Engineering Journal](./Engineering%20Journal/WRO%202025%20JOURNAL.pdf)**

The engineering journal is the comprehensive documentation of our entire development process, design decisions, testing results, and project evolution. It provides detailed insights into:
- Design methodology and iterations
- Technical challenges and solutions
- Testing protocols and results
- Team collaboration and project timeline

## 🗂️ Repository Structure

### 📁 **Engineering Journal/**
Contains the main project documentation:
- `WRO 2025 JOURNAL.pdf` - Complete engineering documentation and project narrative

### 💻 **SRC/** - Source Code
Main codebase for the autonomous vehicle:
- `camera/` - Computer vision and image processing modules
- `final/` - Production-ready code and main control systems
- `gyro/` - Gyroscope sensor integration and orientation tracking
- `lidar/` - LiDAR sensor drivers and obstacle detection
- `motor/` - Motor control and movement systems
- `servo/` - Servo motor control for steering mechanisms
- `Simulation/` - Testing and simulation environments
- `The Taxi/` - Specific challenge implementation code
- `.venv/` - Python virtual environment for dependency management

### 🔧 **3D Models/** - Mechanical Design
CAD files and 3D printable components:
- `STEP/` - Standard 3D model files for manufacturing
- `V1/` - First iteration designs and prototypes
- `V2/` - Second iteration improvements and refinements

### 📋 **3D Printing Profiles/**
Optimized printing settings and profiles for manufacturing vehicle components

### ⚡ **Circuit Schematics/**
Electrical system documentation:
- `Power Map.svg` - Power distribution and electrical layout
- `Schematic_WRO-2025_2025-08-22.svg` - Complete circuit diagrams

### 📸 **Team-Photos/**
Documentation of team members and collaboration

### 🚗 **Vehicle-Photos/**
Visual documentation of the physical vehicle and its development stages

## 🚀 Getting Started

1. **Read the Engineering Journal** - Start with the PDF in the `Engineering Journal/` folder for complete project context
2. **Explore the Code** - Check out the `SRC/` directory for the software implementation
3. **Review Designs** - Look at `3D Models/` and `Circuit Schematics/` for hardware details
4. **See the Vehicle** - Browse `Vehicle-Photos/` to see the physical implementation

## 🛠️ Development Environment

This project uses Python for the main control software. The virtual environment is set up in `SRC/.venv/` with all necessary dependencies.

## 📋 Competition Context

This repository represents our complete solution for the WRO 2025 autonomous vehicle challenge, including:
- Autonomous navigation and obstacle avoidance
- Computer vision for environmental perception
- Sensor fusion for robust decision making
- Real-time control systems for vehicle operation
